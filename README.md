# Flutter Calculator App

A simple and attractive calculator app built using Flutter. 
It supports basic arithmetic operations and includes a backspace button to remove a digit.

## Features
- Add, subtract, multiply, divide
- Remove last digit (backspace functionality)
- Clear button to reset calculations
- Modern and responsive UI
